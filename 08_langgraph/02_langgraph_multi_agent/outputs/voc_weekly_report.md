# 고객센터 주간 VOC 보고서

## 주간 운영 요약

문의는 결제 영역을 중심으로 발생했으며 로그인과 배송 문의가 뒤를 이었다. 전반적인 해결률은 팔십 퍼센트로 유지됐지만 미해결 문의 세 건 중 두 건이 High 우선순위이고 SLA 초과도 발생해, 고객 불편이 장기화되거나 추가 문의로 이어질 가능성이 확인됐다. 특히 모바일 결제 오류와 배송 관련 이슈에 대한 신속한 원인 점검과 후속 관리가 필요하다.

## 주요 VOC

### 미해결 사례

- `T004` 결제 · high: 모바일 결제 단계에서 반복 오류
- `T007` 배송 · high: 출고 완료 후 배송 위치 확인 불가
- `T011` 배송 · medium: 배송지 변경 요청이 주문에 반영되지 않음

### 분석 결과

- 결제 문의가 가장 큰 비중을 차지했으며, 모바일 결제 단계에서 반복 오류가 발생해 결제 완료를 방해하는 핵심 불편 요인으로 보인다.
- 배송 영역에서는 출고 이후 배송 위치를 확인할 수 없는 문제와 배송지 변경 사항이 주문에 반영되지 않는 문제가 함께 나타나 배송 연동 및 주문 변경 프로세스의 점검 필요성이 드러났다.
- 미해결 문의 가운데 High 우선순위가 다수를 차지하고 SLA 초과 건도 발생해, 단순 문의 처리보다 긴급 이슈의 선별과 진행 상황 안내가 중요하다.

## 권장 조치

- 모바일 결제 반복 오류의 발생 조건과 재현 여부를 우선 확인하고 결제 시스템 및 연동 구간의 원인을 점검한다.
- 배송 위치 조회 불가 건은 출고·배송 연동 상태를 확인하고, 배송지 변경 요청 미반영 건은 주문 변경 프로세스와 관련 부서 처리 흐름을 점검한다.
- High 우선순위 미해결 건을 우선 배정해 처리 일정을 관리하고, SLA 초과 건은 지연 사유와 후속 조치 현황을 고객에게 안내한다.
